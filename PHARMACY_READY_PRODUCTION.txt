🔧 TECHNICAL DETAILS

  BACKEND API ENDPOINTS:

  GET /pharmacy/search?q=<query>
  ├─ Required: q parameter (min 2 chars)
  ├─ Returns: JSON array with 10 results max
  └─ Response: [{id, name, brand, category, price, stock, supplier}]

  POST /pharmacy/upload-medicines
  ├─ Input: FormData with .xlsx/.csv file
  ├─ Returns: {success, inserted, updated}
  └─ Columns: medicine_name, brand, category, price, stock, supplier

  POST /pharmacy/add-medicine
  ├─ Input: JSON {name, brand, category, price, stock, supplier}
  ├─ Returns: {success, medicine}
  └─ All numeric fields validated

  POST /pharmacy/add-stock ⭐ NEW
  ├─ Input: JSON {medicine_id, quantity, notes}
  ├─ Returns: {success, message, medicine}
  └─ Updates: stock = old_stock + quantity

🐛 TROUBLESHOOTING

  If autocomplete not working:
  1. Check browser console (F12) for errors
  2. Verify medicines exist: SELECT COUNT(*) FROM medicines;
  3. Test API manually: /pharmacy/search?q=par
  4. Check network tab in DevTools

  If Add Stock modal errors:
  1. Verify medicine is selected
  2. Ensure quantity > 0
  3. Check browser console for error
  4. Verify database connection

  If upload fails:
  1. Check file format (.xlsx or .csv only)
  2. Verify column names are exact
  3. Check file not corrupted
  4. Check terminal for error message
