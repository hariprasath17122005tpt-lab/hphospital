```
MEDICAL BLUE #0052A3

STATUS COLORS
├─ Success Green #059669 (Healthy)

└─ Info Blue #0284C7 (Information)

NEUTRAL COLORS
├─ Text Primary #1A202C (Very dark, high contrast)
├─ Text Secondary #4B5563 (Body text)
├─ Background #FFFFFF (Clean)
└─ Background Secondary #F8FAFB (Soft off-white)
```

### Why This Color Palette?
```
Johns Hopkins Medicine → Medical Blue, Professional
UCLA Health → Teal & Blues, Clinical
Houston Methodist → Navy & Professional
→ Our system matches industry leaders
```

### Typography (Professional)
```
System Font Stack
├─ -apple-system (macOS)
├─ BlinkMacSystemFont (Safari)
├─ 'Segoe UI' (Windows)
└─ 'Helvetica Neue' (fallback)

Sizes:
├─ H1: 32px, 600 weight (Page titles)
├─ H2: 24px, 600 weight (Sections)
├─ H3: 18px, 600 weight (Cards)
├─ Body: 14px, 400 weight (Content)
└─ Small: 12px, 400 weight (Metadata)

Why System Fonts?
✓ Native feel across all platforms
✓ Optimized font rendering
✓ Faster load times
✓ Professional appearance
✓ High readability
```
