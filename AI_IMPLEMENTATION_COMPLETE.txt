## 🔍 HOW IT WORKS NOW

### Response Generation Flow

```
User Types: "What causes fever?"
    ↓
Flask Route (/api/symptom-chat)
    ↓
medical_ai Service
    ↓
Is fine-tuned model loaded?
    ├─ YES: Use AI to generate response
    │   ├─ Create medical-aware prompt
    │   ├─ Run through Llama-2-7B
    │   └─ Return AI response ✓
    │
    └─ NO: Use fallback response
        ├─ Check keywords
        └─ Return safe response ✓
    ↓
Return to Browser
    ↓
User Sees Response
```

## 🆘 TROUBLESHOOTING

### "ModuleNotFoundError: No module named 'peft'"
**Solution:** Already fixed! Package installed.

### "CUDA out of memory"
**Solution:** Script uses 4-bit quantization. If still failing:
- Reduce batch size in train.py
- Use CPU instead (slower but works)

### "Training seems stuck"
**Solution:** This is normal! Monitor with:
```bash
nvidia-smi  # Check GPU usage (if you have GPU)
```

### "Chat responses are generic"
**Solution:** Model is still training or training incomplete.
- Check if `finetuned_health_ai/` folder exists
- Restart Flask server after training
- Clear browser cache

### "Model file too large"
**Solution:** Model is ~7GB (quantized). Need ~20GB free space.
