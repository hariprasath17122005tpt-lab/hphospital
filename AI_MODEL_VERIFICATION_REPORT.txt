🔧 TROUBLESHOOTING
================================================================================

If you see "Could not connect to local AI server":
   1. Check Ollama is running: Type "ollama list" in PowerShell
   2. If needed, restart: powershell and run "ollama serve"
   3. Model takes 5-10 seconds first load, then caches

If responses are slow:
   1. Normal - first load is always slower
   2. Subsequent requests are typically 7-15 seconds
   3. Close background apps to free GPU memory
   4. GPU: nvidia-smi shows VRAM usage

If model not found:
   1. Run: ollama pull neural-chat
   2. Wait for download (~4GB)
   3. Then retry your question
