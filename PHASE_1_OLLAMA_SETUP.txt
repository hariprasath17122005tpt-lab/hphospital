# ==========================================
# PHASE 1: OLLAMA SETUP & MODEL INSTALLATION
# ==========================================

## RECOMMENDED MODEL: Neural Chat 7B (by Intel)
##
## Why this model?
## - Only 7B parameters (lightweight)
## - Runs smoothly on RTX 3050 + 16GB RAM
## - Good for conversation (medical + general)
## - Low hallucination compared to bigger models
## - Fast inference (3-5 sec per response)
## - Can run at 8-bit quantization (saves VRAM)
##
## VRAM Requirements:
## - Neural Chat 7B: ~6-8 GB VRAM (with quantization)
## - RAM Usage: ~4-6 GB
## - Total: Fits comfortably in 16GB system

==========================================
STEP 1: DOWNLOAD AND INSTALL OLLAMA
==========================================

1. Go to: https://ollama.ai
2. Download for Windows
3. Run installer (ollama-windows.exe)
4. Follow installation wizard
5. Ollama will be added to your system PATH

Verify installation:
```bash
ollama --version
```

Expected output:
ollama version X.X.X

==========================================
STEP 2: DOWNLOAD NEURAL CHAT MODEL
==========================================

Open PowerShell and run:

```bash
ollama pull neural-chat
```

OR for better performance (Q4 quantization):

```bash
ollama pull neural-chat:7b-v3-q4_0
```

Wait time: ~5-10 minutes (model is ~4GB)

What happens:
- Ollama downloads the model
- Stores in: C:\Users\<YourUsername>\.ollama\models
- Automatically quantizes to optimal format

==========================================
STEP 3: VERIFY MODEL IS WORKING
==========================================

Open PowerShell and run:

```bash
ollama serve
```

Expected output:
```
loading model
listening on 127.0.0.1:11434
```

Keep this terminal open (Ollama server running).

In ANOTHER PowerShell window, test:

```bash
curl -X POST http://localhost:11434/api/generate `
  -H "Content-Type: application/json" `
  -d '{"model": "neural-chat", "prompt": "What is fever?", "stream": false}'
```

Expected response: JSON with AI response about fever

==========================================
STEP 4: VERIFY GPU ACCELERATION
==========================================

When Ollama starts, check for:
- "GPU acceleration" or "CUDA" in output = GPU working ✅
- No GPU errors = CPU fallback (slower but works)

For NVIDIA GPU verification:

```bash
nvidia-smi
```

Should show:
- NVIDIA RTX 3050
- CUDA capability available

==========================================
STEP 5: TROUBLESHOOTING
==========================================

Problem: "Model not found"
Solution: 
  - Make sure Ollama server is running (ollama serve)
  - Model must be downloaded first (ollama pull neural-chat)

Problem: "Connection refused"
Solution:
  - Make sure port 11434 is not blocked
  - Only one Ollama instance should run

Problem: "Slow responses (>20 seconds)"
Solution:
  - Check GPU: nvidia-smi
  - Restart Ollama: Stop and run "ollama serve" again
  - Reduce context length in Python code

Problem: "Out of memory"
Solution:
  - Close other applications
  - Use quantized model: neural-chat:7b-v3-q4_0
  - Reduce num_ctx to 512

==========================================
STEP 6: KEEP OLLAMA RUNNING
==========================================

For development:
- Keep terminal with "ollama serve" open
- Ollama runs on http://localhost:11434

For production:
- Run Ollama as Windows Service
- Or use: nssm (Non-Sucking Service Manager)

Command to install as service:
```bash
nssm install Ollama "C:\path\to\ollama" serve
nssm start Ollama
```
