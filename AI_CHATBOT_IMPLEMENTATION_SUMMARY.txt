================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

Problem: "Connection refused to localhost:5000"
Fix: Flask not running - Run: python PHASE_2_FLASK_BACKEND.py

Problem: "Cannot connect to Ollama"
Fix: Ollama not running - Run: ollama serve in new terminal

Problem: "Model not found: neural-chat"
Fix: Model not downloaded - Run: ollama pull neural-chat

Problem: "Slow responses (>20 seconds)"
Fix: Check GPU - Run: nvidia-smi
     May be using CPU instead of GPU
     Restart Ollama and Flask

Problem: "Out of memory error"
Fix: Close other applications
    Restart computer
    Reduce num_predict in code

Problem: "Port 5000 already in use"
Fix: Change port in PHASE_2_FLASK_BACKEND.py
    Or: netstat -ano | findstr :5000 (find process)
