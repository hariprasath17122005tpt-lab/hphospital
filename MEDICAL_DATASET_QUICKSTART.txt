INTEGRATION WITH FLASK (OPTIONAL)
================================================================================

To use with Flask API:

1. Update app/routes/features.py:

from simple_direct_chatbot import SimpleMedicalChatbot

chatbot = SimpleMedicalChatbot()

@app.route('/features/api/symptom-chat', methods=['POST'])
def symptom_chat():
    data = request.json
    message = data.get('message', '')
    response = chatbot.chat(message)
    return jsonify({'response': response})

2. Restart Flask server
3. Test the endpoint:

curl -X POST http://localhost:5000/features/api/symptom-chat \
  -H "Content-Type: application/json" \
  -d '{"message":"fever"}'
