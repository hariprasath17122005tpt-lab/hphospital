🐛 TROUBLESHOOTING

Problem: "AI still responds slowly"
Solution:
  1. Check if question is in FAQ → Add it!
  2. Try reducing max_new_tokens to 50
  3. Check system CPU usage
  4. Verify model warm-up completed

Problem: "First response takes 10+ seconds"
Solution:
  Normal! Model warming up for first time.
  Subsequent responses: 5-10 seconds
  Add question to FAQ for instant future answers

Problem: "AI gives very short answers"
Solution:
  Intentional! Doctors prefer concise responses.
  Need longer? Increase max_new_tokens to 150

Problem: "AI doesn't answer specific question"
Solution:
  1. Add to MEDICAL_FAQ dictionary
  2. Or add to MEDICAL_KNOWLEDGE dictionary
  3. Restart server (Ctrl+C, then python run.py)
