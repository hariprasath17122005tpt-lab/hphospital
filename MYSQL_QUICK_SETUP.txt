## 🆘 If Something Goes Wrong

### MySQL not found?
```powershell
# Install it first from: https://dev.mysql.com/downloads/mysql/
# Then run setup again
```

### Wrong MySQL password?
```powershell
# Run setup again with correct password
python MYSQL_QUICKSTART.py
```

### Database already exists?
```powershell
# It will overwrite and recreate fresh tables
# All old data will be removed
python MYSQL_QUICKSTART.py
```

### Connection error?
```powershell
# Make sure MySQL is running
Get-Service | findstr MySQL
# Should see: MySQL80  Running
```
