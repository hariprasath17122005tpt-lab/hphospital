═══════════════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ PROBLEM: "This site can't be reached" / Connection refused

✅ SOLUTION:
   1. Check terminal output - server should show "Running on..."
   2. Wait 2-3 seconds for server to fully start
   3. Click "Reload" in browser or press F5
   4. Try different URL: http://127.0.0.1:5000
   5. Check port 5000 is not used: netstat -ano | findstr ":5000"

❌ PROBLEM: Login not working

✅ SOLUTION:
   1. Check spelling of username/password
   2. Try: john_patient / password123
   3. Reset database: python init_db.py
   4. Restart server: python run.py

❌ PROBLEM: Features not loading

✅ SOLUTION:
   1. Check browser console (F12 > Console tab)
   2. Refresh page (F5)
   3. Clear browser cache
   4. Try different browser
