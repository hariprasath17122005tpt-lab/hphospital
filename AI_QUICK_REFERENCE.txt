- Input limited to 150 chars

- 11 medical conditions with pre-written answers
- Always available as backup
- Returns in 0.1 seconds

## 🚨 Troubleshooting

### "AI is still slow"
1. Check if question is in FAQ → Add it!
2. Check terminal for warm-up message
3. Reduce `max_new_tokens` from 100 to 50

### "First question takes too long"
- Normal! Model is warming up (5-10 sec)
- Subsequent questions will be faster
- This only happens once per server start

### "AI gives very short answers"
- That's intentional! Doctors prefer concise answers
- If you need longer answers: Increase `max_new_tokens` to 150
