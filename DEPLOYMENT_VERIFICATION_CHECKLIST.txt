PHASE 1: ENVIRONMENT SETUP
================================================================================

Install Ollama:
  [_] Download from https://ollama.ai
  [_] Run installer (ollama-windows.exe)
  [_] Accept all defaults
  [_] Restart computer (optional)
  [_] Verify: ollama --version (in PowerShell)
  [_] Expected output: "ollama version 0.X.X"

Download Model:
  [_] Open PowerShell
  [_] Run: ollama pull neural-chat
  [_] Wait for completion (~10 minutes, ~4GB)
  [_] Verify: ollama list (should show neural-chat)
  [_] Expected output: "neural-chat   latest  4.0GB"

Install Python Dependencies:
  [_] cd to hospital folder
  [_] Run: pip install -r AI_CHATBOT_REQUIREMENTS.txt
  [_] Verify: pip list (should show flask, flask-cors, requests)
  [_] No error messages

PHASE 2: START SERVICES
================================================================================

Terminal Window 1 - Start Ollama:
  [_] Open PowerShell
  [_] Type: ollama serve
  [_] Press Enter
  [_] Check output: "loading model"
  [_] Check output: "listening on 127.0.0.1:11434"
  [_] Do NOT close this window
  [_] Leave it running throughout tests

Terminal Window 2 - Start Flask:
  [_] Open NEW PowerShell
  [_] cd to hospital folder
  [_] Type: python PHASE_2_FLASK_BACKEND.py
  [_] Press Enter
  [_] Check output: "Hospital Management System - AI Medical Chatbot"
  [_] Check output: "Running on http://localhost:5000"
  [_] Do NOT close this window
  [_] Leave it running throughout tests

Terminal Window 3 - Verify Both Running:
  [_] Open NEW PowerShell
  [_] Type: curl http://localhost:11434/api/tags
  [_] Should return JSON (Ollama is running)
  [_] Type: curl http://localhost:5000/api/health
  [_] Should return: {"status": "ok", "ollama": "running"}

PHASE 4: MANUAL VERIFICATION TESTS
================================================================================

Test 1: Health Check
  [_] In PowerShell, run:
      curl http://localhost:5000/api/health
  [_] Should return: {"status": "ok"}
  [_] Status code: 200

Test 2: Info Endpoint
  [_] In PowerShell, run:
      curl http://localhost:5000/api/ai-info
  [_] Should return: Chatbot information
  [_] Contains: "neural-chat" model
  [_] Status code: 200

Test 3: Simple Query (Fever)
  [_] In PowerShell, run:
      curl -X POST http://localhost:5000/api/ai-chat `
        -H "Content-Type: application/json" `
        -d '{"message": "I have a fever"}'
  [_] Status code: 200
  [_] Response contains: "fever", "temperature", "doctor"
  [_] Response time: 2-10 seconds
  [_] Processing time shown in response

Test 4: Complex Query (Fever + Asthma)
  [_] In PowerShell, run:
      curl -X POST http://localhost:5000/api/ai-chat `
        -H "Content-Type: application/json" `
        -d '{"message": "i have fever with asthma"}'
  [_] Status code: 200
  [_] Response mentions both fever and asthma
  [_] Response includes safety warning

Test 5: Medication Query
  [_] In PowerShell, run:
      curl -X POST http://localhost:5000/api/ai-chat `
        -H "Content-Type: application/json" `
        -d '{"message": "Can I take paracetamol"}'
  [_] Status code: 200
  [_] Response cautious (doesn't prescribe)
  [_] Recommends consulting doctor
  [_] No specific dosage given

Test 6: Error Handling (Empty Message)
  [_] In PowerShell, run:
      curl -X POST http://localhost:5000/api/ai-chat `
        -H "Content-Type: application/json" `
        -d '{"message": ""}'
  [_] Status code: 400
  [_] Response: error message
  [_] Not 500 (server error)

Test 7: Test Without Ollama Running
  [_] Stop Ollama (close Terminal 1)
  [_] Try to send query (as in Test 3)
  [_] Status code: 503
  [_] Response: "Ollama server is not running"
  [_] Restart Ollama
  [_] Verify it works again
