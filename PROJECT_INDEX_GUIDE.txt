PATH 1: FASTEST SETUP (45 minutes)
==================================
1. Download Ollama from https://ollama.ai
2. Install (accept defaults)
3. Open PowerShell: ollama serve
4. New PowerShell: ollama pull neural-chat (wait ~10 min)
5. New PowerShell: pip install -r AI_CHATBOT_REQUIREMENTS.txt

API ENDPOINTS SUMMARY
================================================================================

POST /api/ai-chat
  Purpose: Send medical query to AI
  Input: {"message": "medical question"}
  Output: {"success": true, "response": "...", "processing_time_ms": 2500}
  Status: 200 (success), 400 (bad input), 503 (Ollama down)

GET /api/health
  Purpose: Check if system is healthy
  Input: None
  Output: {"status": "ok", "ollama": "running"}
  Status: 200 (healthy), 503 (Ollama down)

GET /api/ai-info
  Purpose: Get chatbot information
  Input: None
  Output: {"name": "Hospital AI...", "model": "neural-chat", ...}
  Status: 200 (success), 503 (Ollama down)
