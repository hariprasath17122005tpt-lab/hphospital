WHAT THE CHATBOT DOES
================================================================================

ACCEPTS INPUT:
  User Query: "I have a fever"
              "Can I take paracetamol?"
              "Stomach pain treatment"
              "What causes headaches?"

PROCESSES:
  1. Validate input
  2. Send to Ollama
  3. Apply safety prompt
  4. Generate response (2-5 sec)
  5. Format output
  6. Add disclaimer

RETURNS OUTPUT:
  - Medical information (not diagnosis)
  - Safety warnings when needed
  - Doctor consultation recommendation
  - Clear, 5-6 line response
  - Processing time shown
  - Full JSON API response

EXAMPLE OUTPUT:
  "A fever is when your body temperature rises above 98.6°F (37°C).
   Common causes include viral or bacterial infections.
   Rest adequately and stay hydrated with water and fluids.
   Use Paracetamol if needed and monitor your temperature.
   Seek medical attention if fever exceeds 104°F or lasts >3 days.
   Please consult a healthcare professional."
